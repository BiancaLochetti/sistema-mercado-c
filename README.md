# Sistema de Mercado em C

Projeto desenvolvido em linguagem C para praticar conteúdos importantes da programação, como:

- Struct
- Vetores
- Matrizes
- Estruturas de repetição
- Estruturas condicionais

---

## Funcionalidades

O sistema permite:

- Cadastro de cliente
- Cadastro de produtos
- Registro das compras
- Cálculo do valor total da compra
- Aplicação de desconto para clientes fidelidade
- Exibição do resumo da compra

---

## Estruturas utilizadas

### Structs
- Cliente
- Produto

### Vetores
- Vetor de produtos
- Vetor de clientes

### Matrizes
A matriz de compras armazena:
- ID do produto
- Quantidade
- Preço unitário
- Subtotal

---

## Regras de desconto

Clientes com fidelidade recebem:

- 5% de desconto para compras abaixo de R$100
- 10% de desconto para compras entre R$100 e R$500
- Compras acima de R$500 não recebem desconto

---

## Tecnologias utilizadas

- Linguagem C
- Biblioteca `stdio.h`
- Biblioteca `stdlib.h`

---

## Objetivo do projeto

Projeto desenvolvido para fins acadêmicos, com o objetivo de praticar lógica de programação e a utilização de structs, vetores e matrizes em linguagem C.
